# Plate Trainer

GeoGuessr licence-plate trainer: multiple choice, duel between two lookalikes, or typed answer, plus a study gallery.

- Wrong answer: the plate of the country you picked is shown next to the correct one, with a look-similarity score (Jaccard index of look tags).
- Mix-ups are kept in the browser (localStorage) and listed in Study, with a "Drill my mix-ups" duel round.
- Deep link: `#fr` (ISO code, lowercase) opens Study filtered on that country.

## Deploy on GitHub Pages
Push the contents of this folder (index.html, data/, images/) to a repo → Settings → Pages → Deploy from branch `main` / root.

## Adding plates
Drop the image in `images/` and add a line to `data/plates.js`:

```js
{"id": "any-unique-id", "img": "images/my-plate.jpg", "country": "Peru", "continent": "South America",
 "mustLearn": false, "tags": ["white-long"], "lookalikes": ["Bolivia", "Chile"], "note": "What to look for."}
```

- `country` must match a name in `data/countries.js` (add it there if missing).
- `tags` come from `TAG_LABELS` in `countries.js`; they drive the category filters and the "hard" distractors.
- `lookalikes` are always preferred as wrong answers.

## Key differences between lookalikes
`data/pairs.js` holds a short note per pair of countries, shown when you mix them up. Key = the two names sorted alphabetically, joined by `|`.

## Front plates map (Study → Front plates map, or `#front`)
Which US states, Canadian provinces and Mexican states require a front plate.
- Rules and notes: `data/frontplates.js`, edited by hand (sources in its header).
- Outlines: `data/frontmap.js`, generated by `python tools/build_frontmap.py <ne_10m_admin_1_states_provinces.geojson>`
  from Natural Earth (public domain). Only needed again to change the map itself.

## Regional mode (Quiz → Game: "Mexico states", Study → "Mexico states", or `#mx`)
A Street View crop is shown, you click the state on the map. After answering: reference plate of the state you
clicked vs the right one, plus other crops of the same design.
- Data: `data/regions/mx.js` (`units[CODE].designs = [{refs, crops: [{img, blur?}]}]`, CODE = ISO 3166-2 suffix).
  `blur: 1` marks crops sharp enough to read; the app blurs them. Images in `images/mx/`.
- Source: "Applicably Guessable Mexico Plates Documentation" (community Google Doc). Mexico City, Morelos and
  Nuevo León have no plate yet.
- Map: `data/regions/mx-map.js`, generated by `python tools/build_regionmap.py <ne_10m_admin_1_states_provinces.geojson> MEX data/regions/mx-map.js mx`.
  Another country = one data file + one map file with the same key, plus two `<script>` lines in index.html.
